# E-PROFILER — Rozszerzenie Chrome & Edge (Manifest V3)

Oficjalny rejestrator wideo oraz inteligentny asystent VOD platformy **E-PROFILER**.

## Możliwości
1. **Bypass zabezpieczeń DRM (Widevine / FairPlay):** Rejestruje obraz i dźwięk bezpośrednio ze zdekodowanego strumienia odtwarzacza w przeglądarce.
2. **Pływający HUD na stronach wideo:** Automatycznie wykrywa obecność odtwarzaczy na portalach takich jak TVN24 GO, TVP VOD, Polsat Box Go, YouTube, Sejm RP i wyświetla dyskretny przycisk `E-PROFILER`.
3. **Sygnalizacja stanu odtwarzacza:** Informuje o pauzie, braku zalogowania lub gotowości materiału.
4. **Jedno kliknięcie do audytu:** Po zakończeniu nagrania przesyła materiał do silnika AI i otwiera gotowy raport w serwisie `eprofiler.pl`.

## Szybka instalacja (30 sekund)
1. Rozpakuj archiwum `eprofiler-chrome-extension.zip` do wybranego folderu na dysku.
2. Otwórz przeglądarkę (Chrome / Edge / Brave / Opera) i przejdź pod adres:
   `chrome://extensions`
3. Włącz przełącznik **Tryb dewelopera** (prawy górny róg).
4. Kliknij **Załaduj rozpakowane** (Load unpacked) i wskaż folder `extension/`.
5. Gotowe! Ikona E-PROFILER pojawi się na pasku rozszerzeń przeglądarki.
